## Recommendation

- Short-term (safe): keep scripts as-is; for scripts that call the DB and are part of automation (e.g. `scripts/run_migrations.py`), consider a small wrapper that imports `api.db.DB_PATH` and uses it.
- Medium-term: convert `api/*` modules to use `api.db.get_db()` (already done for many files). For `etl/` and `ml/` code, accept `db_path` as a parameter and pass `api.db.DB_PATH` when called from the app or CI.
- Long-term: add a small adapter module `scripts/db_wrapper.py` that exposes `connect()` using `api.db.DB_PATH` or environment variable override.
