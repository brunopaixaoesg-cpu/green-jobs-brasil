Como rodar a demo (PowerShell)

1) Abrir o terminal

Caminho do projeto

cd "C:\Users\Bruno\Empresas Verdes"
2) Orquestrar tudo

Executa preparação completa

powershell -ExecutionPolicy Bypass -File .\scripts\demo_playbook.ps1
3) (Opcional) Reinstalar deps

Caso bibliotecas faltem

powershell -ExecutionPolicy Bypass -File .\scripts\demo_playbook.ps1 -ReinstallDeps
4) (Manual) Iniciar API

Alternativa ao script

python start_api.py

Roteiro de apresentação (10–15 min)

  • 1. /docs e /kpis (contexto e maturidade)
  • 2. Profissionais: /test-api (UF/ODS/experiência e ordenação)
  • 3. Empresas: UF, score mínimo, setor (vagas/candidaturas)
  • 4. Vagas: UF, remoto, salário mínimo, nível (enriquecido)
  • 5. Dashboard Empresa (encerramento)

Endpoints úteis

GET /api/profissionais?uf=SP,RJ&ods=7,13&anos_exp_min=3&nivel=pleno&sort=anos_experiencia_esg&order=desc&page=1&limit=10
GET /empresas/api/listar?uf=SP&score_min=70&setor=energia&sort=score_verde&order=desc&page=1&limit=10
GET /api/vagas?uf=SP&salario_min=7000&remoto=true&nivel=pleno&sort=salario_max&order=desc&page=1&limit=10

Quando algo não inicia

  • Porta 8002 ocupada → finalize processo Python e reinicie
  • Dependências → pip install -r requirements.txt (e/ou api/requirements.txt)
  • Banco vazio → GET /api/populate ou python scripts/popular_dados_demo.py
