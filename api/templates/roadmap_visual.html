Atualizado em 2025-11-01 • Plataforma ESG com API, ML e dashboards
Salvar em PDF 📘 Playbook

Visão e objetivos

  • Mapear e classificar empresas verdes (Core/Adjacent/Secondary) conectadas a ODS
  • Expor dados via API REST e dashboards para profissionais e empresas
  • Oferecer matching inteligente (ML) explicável e realista
  • Preparar base para escalabilidade (dados RFB) e deploy em produção

Entregas concluídas (MVP v1.6)

Banco de dados

SQLite • 43 CNAEs verdes • 10 empresas • 857 candidaturas

  • Relacionamentos empresa ⇄ CNAE; ODS e score verde
  • Dados demo: 101 vagas, 120 profissionais

ETL (DuckDB + SQLite)

  • Mapeamento CNAE verde + cálculo de score
  • Particionado por UF (Parquet) e carga no SQLite

API (FastAPI)

  • Rotas: /empresas, /cnaes, /stats, /health, /info
  • Busca por CNPJ e KPIs consolidados

Dashboards e UI

  • Dashboard Profissional v1.4 • Dashboard Empresa v1.5
  • ML Dashboard e templates Jinja2

Storytelling Profissional v1.6

12 campos narrativos + página dedicada

Autenticação v1.3

Hash SHA256, sessões por token, login de empresa

Operação e DX

  • Scripts de inicialização e preparação de demo
  • Suite de testes essenciais e documentação
