## 1. Quem Somos

A **Green Jobs Brasil** é uma plataforma de infraestrutura de dados que conecta empresas sustentáveis, profissionais qualificados e políticas públicas. Nosso diferencial é a **classificação sistemática de atividades econômicas verdes** baseada em CNAEs e alinhamento com ODS.

**Números atuais**:
- 🏢 ~1.000 empresas mapeadas e classificadas
- 📊 43 CNAEs verdes identificados (nível de classe, 5-7 dígitos)
- 💼 Sistema de scoring 0-100 baseado em evidências
- 🔗 API aberta para integração com sistemas públicos e privados
- 📈 3+ anos de operação e aprendizados práticos

**Nossa missão** está totalmente alinhada com a TSB: **tornar a transição verde mensurável, rastreável e acionável**.

## 3. O Que Podemos Oferecer ao CITSB?

### 3.1 Experiência Prática Imediata

**Mapeamento CNAE → Sustentabilidade (43 CNAEs atuais)**:
- Energia renovável: Solar, eólica, hidro, biomassa
- Gestão de resíduos: Reciclagem, compostagem, economia circular
- Transporte limpo: Logística verde, mobilidade urbana
- Construção sustentável: Eficiência energética, certificações
- Bioeconomia: Produtos da sociobiodiversidade

**Formato**: Planilha com CNAE, descrição, justificativa, scoring, fontes científicas  
**Disponibilidade**: Compartilhamos gratuitamente para uso da TSB

### 3.2 Infraestrutura Tecnológica Pronta

**API de dados** (`api.greenjobsbrasil.com.br/docs`):
- Consulta por CNPJ: Retorna CNAEs, score verde, ODS alinhados
- Consulta por CNAE: Lista empresas elegíveis
- Estatísticas agregadas: Setores, regiões, ODS
- **Oferta**: Customizar para critérios TSB (CS/NPS/SM)

**Dashboard interativo**:
- Auto-avaliação de conformidade para empresas
- Visualização de score por dimensão (ambiental, social, governança)
- Geração de relatórios exportáveis (PDF, CSV)
- **Oferta**: Adaptar para dashboard oficial TSB

**ETL (Extract, Transform, Load)** automatizado:
- Integração com API da Receita Federal (CNPJs e CNAEs)
- Processamento mensal de milhares de empresas
- Scripts Python open-source no GitHub
- **Oferta**: Compartilhar código para escala nacional

### 3.3 Capacidade de Execução de Pilotos

**Proposta concreta**:

**Fase 1: Pilotos Setoriais (3 meses)**
- Escolher 2 setores prioritários (sugestão: **Energia (D)** e **Transporte (H)**)
- Implementar critérios TSB na plataforma Green Jobs Brasil
- Classificar 100 empresas reais por setor (total: 200 empresas)
- Gerar relatório de aprendizados:
  - Facilidade de aplicação dos critérios
  - Dados disponíveis vs. dados necessários
  - Gaps de informação
  - Sugestões de refinamento

**Fase 2: Dashboard de Conformidade TSB (6 meses)**
- Co-desenvolver ferramenta oficial de auto-avaliação
- Integração com bases governamentais (IBAMA, ICMBio, MTE para SM)
- API pública de consulta da TSB
- Sistema de versionamento (rastreabilidade)

**Fase 3: Escala Nacional (12 meses)**
- Classificar 50.000+ empresas nos 8 setores da TSB
- Dados abertos para políticas públicas e pesquisa
- Integração com SINE (direcionamento de qualificação profissional)
- Painel analítico para o CITSB (estatísticas nacionais)

**Investimento estimado**: R$ 500k - R$ 1M  
**Contrapartida**: Credenciamento como ferramenta oficial TSB

### 3.4 Contribuição para Consulta Pública

Já preparamos uma **contribuição técnica de 40+ páginas** com:
- Análise detalhada de cada setor (D, H, A, E, turismo)

- Proposta de dados abertos e API oficial
