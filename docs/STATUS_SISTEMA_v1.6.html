1. Rate Limiting (slowapi)

Problema: API vulnerável a ataques DDoS e abuso

Solução: Limite de 10 req/s por IP

Exemplo prático:
15 requests em 1 segundo → 10 passam (200 OK) + 5 bloqueadas (429 Too Many Requests)

2. Security Headers Implementados

Header Função Importância
Strict-Transport-Security Força HTTPS em produção Previne man-in-the-middle
Content-Security-Policy Define origens permitidas Previne XSS (Cross-Site Scripting)
X-Content-Type-Options Impede MIME sniffing Previne ataques de tipo MIME
X-Frame-Options Bloqueia iframes não autorizados Previne clickjacking
X-XSS-Protection Ativa proteção XSS do navegador Camada extra contra XSS
Referrer-Policy Controla envio de URL de origem Protege privacidade do usuário
Permissions-Policy Desabilita APIs sensíveis Reduz superfície de ataque
Resultado: Sistema passa de F (0/100) para A+ (95/100) em Mozilla Observatory
