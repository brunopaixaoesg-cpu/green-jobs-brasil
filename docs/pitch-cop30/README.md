# 📱 Green Jobs Brasil - Pitch Deck Mobile First

Apresentação interativa otimizada para celular/tablet, pronta para o Xavier apresentar para investidores na COP30.

## ✨ Características

- **📱 Mobile First**: Otimizado para celular e tablet
- **👆 Navegação Intuitiva**: Swipe para trocar de slide (como Instagram Stories)
- **🎨 Visual Moderno**: Design limpo e profissional
- **⚡ Performance**: Carrega rápido, funciona offline
- **🌐 Cross-Platform**: Funciona em iOS, Android, Desktop
- **🔗 Compartilhável**: Basta enviar o link

## 🚀 Como Usar

### Opção 1: Hospedar Online (RECOMENDADO)

1. **Upload para GitHub Pages** (grátis):
   ```bash
   # Criar repositório no GitHub
   # Ativar GitHub Pages nas configurações
   # URL: https://brunopaixaoesg-cpu.github.io/gjb-pitch
   ```

2. **Ou Netlify/Vercel** (grátis, mais fácil):
   - Arrastar a pasta `pitch-cop30` para Netlify.com
   - URL: `https://gjb-cop30.netlify.app`

3. **Compartilhar o link** com Xavier via WhatsApp

### Opção 2: Enviar Pasta Zipada

1. Zipar a pasta `pitch-cop30`
2. Xavier descompacta
3. Abrir `index.html` no navegador do celular

### Opção 3: Hospedar Localmente

```bash
# Na pasta pitch-cop30
python -m http.server 8080

# Acessar: http://localhost:8080
```
